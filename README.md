# CHV Tablero EN CURSO

Lista de asuntos (`CHV-00*`) con tareas anidadas (`CHV-00*-01`). Uso interno.

Repositorio **privado** (no mezclar con `chv-portal`).

## Archivos

- `index.html` — página
- `styles.css` — escritorio y celular
- `app.js` — filtros y acordeón
- `data.js` — lectura v8 del índice

## Página pública (GitHub Pages)

En cuenta gratuita, Pages exige repo público.

1. Settings → General → Danger zone → Change visibility → Public (solo si acepta que el listado quede visible).
2. Settings → Pages → Branch `main` / root → Save.
3. URL: `https://chvillanueva-code.github.io/chv-tablero/`

Mientras el repo sea privado, abrir `index.html` en el navegador o usar el HTML de Drive.
